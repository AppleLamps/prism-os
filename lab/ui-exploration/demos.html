Handwired demos

Every demo page in this repo except the JSON search's, history included, from one server: each page compiles a UI into one fixed numeric program, and JavaScript only records input, runs the program, and copies its outputs onto the page. The demos that the README lists also have an index of their own, at the paths their links are written for: run bun start.

Original repo demos

HandwiredOS

assets/index.html

A desktop with three windows and a dock, where focus, stacking, dragging, resizing, window buttons, springs, the photo viewer and a list of the program's own numbers all run in one compiled program. The note in Notes is the browser's own text field.

Try

  • Drag a title bar, resize a window from its corner, and use the three window buttons; a closed window comes back from the dock.
  • In Photos, click a photo: it zooms from its place in the grid to the open photo. Then use the arrow controls, and click beside the photo to send it back.
  • Click in Notes and type, then click another window: the keyboard focus leaves the text field.
  • In Monitor, scroll the list of the program's operations, click a row, use the arrow keys, Page Up, Page Down, Home and End, and pick State or Outputs in the sidebar to watch values change while you drag a window.

Learned gallery

assets/learned-gallery.html

Backpropagation trains a small geometry network so that its photo layout matches rectangles you sketch, with photo edges that are nearly on one line pulled onto it.

Try

  • In Sketch, drag a rectangle to move it, drag its corner to resize it, click empty space to add one, up to 12, or remove the selected one with Delete; the photos in Learned follow while you drag, and a photo stays in its row or column until its rectangle is about 4% of the stage's width away.
  • Pick Cinema or Contact sheet, or press Retrain, and watch the photos form from a pile while the loss chart under them falls.

Traditional JavaScript tasks, September 17, 2026

Demos of tasks that are usually written in plain JavaScript, to see how one fixed program handles them. Each has a fixed capacity, named outputs for what doesn't fit, and a plain JavaScript reference that its tests compare with.

Search 100,000 JSON documents

assets/json-search.html

From October 13, 2026: the JSON highlighter's and the regex search's programs, each written as one step that a shader loops over a document's positions, run over up to 100,000 JSON documents at once on WebGPU. The page searches them again at each keystroke, and shows the search's time next to native RegExp's.

This server doesn't serve the page: run bun start and open /json-search/. Without WebGPU the page runs both programs on the CPU, in a worker. The measurements are in src/json-search/README.md.

Knuth-Plass line breaking

lab/knuth-plass/demo.html

The paragraphs of pretext's justification demo, broken into lines two ways: pretext's greedy layoutNextLineRange on the left, and on the right the breaks with the smallest total cost, min(slack, 63)² per line in whole pixels, which the program finds as a shortest path over 144 break points.

Try

  • Drag the Column width slider and compare the two columns' line counts, total costs and widest justified spaces.
  • Switch Form to tree, which reloads the page: the same breaks from min-plus matrix products combined with Brent-Kung's network, with 154 layers where the chain has 1,422, and about 6 times the chain's time per frame on the CPU.

?window=16 lines of at most 16 boxes, with a message from 327 px ?check=1 compares every evaluation with the reference README

lists: text rows

lab/ui-exploration/lists/text-rows.html

A list of up to 10,000 chat messages in 64 DOM slots, whose heights come from pretext's line breaks at the container's width, read from breakpoint cells, with appended messages and scroll anchoring when a resize changes every height.

Try

  • The page opens at the end of the rows. Scroll up partway, then drag the Container width slider: the row at the top of the view keeps its position on screen.
  • Press "Edit a row above the view", and nothing in view moves. Press "Append 100" to reach the capacity of 10,000 rows, and the stats line counts the refused appends.

Setup takes about 2 s after load.
