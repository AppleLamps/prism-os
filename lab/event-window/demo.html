Event window

Four windows driven entirely by one compiled numeric circuit stepping closed-loop: every frame is a pure function of the latched press record plus the live pointer. The JavaScript on this page only feeds pointer events into source cells and copies sixteen geometry numbers back onto the screen. Drag a title bar. Click a window to focus it, click its body again to maximize.

One latched press record plus the live pointer is the entire memory of the interaction — nothing accumulates per frame. Latched values stay after release; the active bit gates their meaning. Watch the drag-begin latch flip the instant the pointer crosses the slop threshold.

Behavior cells

These six values are behavior parameter cells inside the running circuit, written between frames. Flip “body drags” and every window becomes draggable anywhere, instantly — zero recompilation. The title-bar strip you see is drawn from the same cell the circuit reads, so the picture and the behavior cannot disagree.
