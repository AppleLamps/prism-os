Handwired
README GitHub

One numeric program runs the whole interface.

Handwired writes an interactive UI as one fixed numeric program with the form of a neural network: layers of weighted sums and ReLU gates, wired by hand with builder functions instead of trained. JavaScript writes inputs such as the pointer’s position into a table of numbers, runs the program, and copies outputs such as each window’s position and size to the page.

Regex search

Type a pattern, and one program finds every match in a text as you type. The pattern reaches the program as tables of numbers, so every pattern runs on the same program.

The JSON highlighter’s program, run on 100,000 documents at once. Every document runs the same operations and reads no other document, so one pass on the GPU computes all of them in parallel.
