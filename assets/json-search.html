Each keystroke turns the pattern into tables of numbers for a fixed program of weighted sums, ReLU gates and table reads, so no pattern is compiled into GPU code. Then one pass on the GPU runs the program once per document, since no document reads another. Each document is JSON of up to 512 characters, colored by a second such program.
